# Práctica de aplicación de estándares de codificación en Java.

| N° | Error que anda mal | Cómo acomodarlo |
|---|---|---|
| 1 | `producto` empieza con minúscula | Cambiarlo a `Producto` (las clases van con mayúscula al inicio) |
| 2 | Las variables están como `public` | Ponerlas en `private` para no dejar los datos desprotegidos |
| 3 | `CODIGO` está todo en mayúsculas | Cambiar a `codigo` en minúsculas |
| 4 | `Nombre` y `Precio` empiezan con mayúscula | Ponerlos en minúscula (`nombre` y `precio`) |
| 5 | Los parámetros `c`, `n`, `p` no dicen nada | Renombrarlos a `codigo`, `nombre`, `precio` para que se entienda |
| 6 | El método `Mostrar()` empieza con mayúscula | Cambiarlo a `mostrar()` |
| 7 | Todo el código está amontonado sin sangría | Darle formato con espacios/tabulaciones para que no se vea feo |
| 8 | Falta espacio después de las comas y signos | Poner espacios en los parámetros (`String c, String n`) para leerlo mejor |
